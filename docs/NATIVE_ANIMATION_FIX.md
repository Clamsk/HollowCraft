# Native alpha.5：原模组动作对照、跳搭与字体

[English](NATIVE_ANIMATION_FIX.en.md) | [安装说明](NATIVE_MIGRATION.md)

本版集中修复独立版的三个回归。它仍是迁移预览，不表示已完成全部桥接功能或通关验收。

## 攻击动作

这次直接检查本机 Better Combat 1.8.5 和 PlayerAnimator 1.0.2-rc1 的字节码，并以原 PlayerAnimator 播放器生成数值参考。

- 原动画没有 `version` 字段，属于旧格式。PlayerAnimator 将旧 `torso` 转为全身 `body`。旧移植错误地只转动胸部，头、手脚和装备没有一起变换。
- 修正默认角度单位、前一关键帧的缓动、虚拟起止关键帧、旋转归一化、循环姿态和 `turn` 导入处理。
- 全身变换发生在原版模型轴转换之前；局部关节发生在之后。两者分别转换，根节点按原播放器的 0.7 格枢轴计算，位置单位也分别使用格和 1/16 格。
- Unity 默认欧拉角顺序与 ModelPart 不同。移除这一混用，按 Minecraft 的 ZYX 顺序转换，并按原 FadeModifier 的角度插值衔接三段攻击。保留 Better Combat 的头部俯仰控制、前摇变速和停止过渡。

开发用对照工具直接调用本机原 JAR，不启动 Minecraft 或空洞。29 份动画的 260,232 个采样轴与原播放器一致（容差 0.0001）；4,782 个骨骼变换后的点与 JOML/Minecraft 矩阵一致，最大误差约 0.000070 格。它验证采样和坐标转换，不能代替画面与手感试玩。原 JAR、反编译输出及生成参考数据不随发布包分发。玩家运行时仍只加载 C# Mod。

## 跳搭

日志中的已销毁敌人引用会在采样状态时抛异常，使同一帧后续的鼠标和跳搭处理被跳过。改用 Unity 的对象存活检查，修复该中断。

保留之前的 1.5 格起跳辅助、脚底目标锁定、场景地面基础方块和预测碰撞。现在起跳前记录实际支撑面，并可从上升运动恢复遗漏的起跳通知；排队放置同时在物理帧检查净空，不再只依赖渲染帧。右键放置确认仍携带当前脚底位置，避免周期状态采样滞后；同一次跳跃的重发不重复消耗方块。

用圆石指向脚下，按住右键和空格可连续跳搭；`B` 保留为辅助跳搭入口。碰撞与连续操作结果仍需玩家实机确认。

## 字体

安装时从校验过的原资源包提取字体 provider 的真实字符表、2,413 个位图字形和字宽。空格只推进原版 4 像素，不再把字图中的某个格子画出来；窄字符、重音字母和文本居中按实际字宽计算。字体纹理使用 Point/Clamp，绘制位置与缩放对齐到整数像素。未覆盖的中文等字符使用系统字体后备，不再显示问号。

新增字体元数据和字图留在本机资源目录，安装包只包含提取脚本；已有用户运行新版安装器会补齐资源。

## 本次交付

主 Mod 编译通过；161 项规则/协议/字体检查、12 项启动器检查通过。上面的原播放器及矩阵对照另行执行。没有启动或关闭游戏，没有修改 Steam 原版程序集或玩家存档。实机外观、实际跳搭成功率、Boss 流程和完整通关尚待试玩。

```powershell
dotnet run --project tools/NativeAnimationCheck -c Release -- artifacts/StandaloneAssets/bettercombat artifacts/native-alpha5-reference/samples.json
```
