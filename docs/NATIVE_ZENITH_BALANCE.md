# Native alpha.11：天顶剑伤害与阶段保护

[English](NATIVE_ZENITH_BALANCE.en.md) | 简体中文

天顶剑改为每轮完整攻击对每个目标合计最多造成 **200 点空洞原生血量**的伤害。没有护盾、无敌或转阶段保护的 2000 血目标需要约十轮命中；按住左键每秒开始两轮攻击。三把飞剑的轨迹、拖尾和剑身轮换保留，同一轮不会因为多把剑、回旋复碰或随机暴击叠加伤害。

旧实现每把飞剑独立反复造成 190 点 MC 代理伤害，另有双倍暴击。空洞敌人的血量经过压缩，190 点代理伤害可能远大于 190 点空洞血量；多飞剑叠加进一步放大了输出。本版从原生最大血量换算伤害，MC 生物则每轮使用 200 点 MC 伤害。

继续沿用空洞原版下一阶段血量边界与原生受击事件。打到边界时舍弃该轮剩余伤害；同一轮的旧飞剑在血量同步、阶段编号变化后也不能再次扣血。下一轮正常攻击仍可命中。松开左键会完成已经开始的一轮，不会在周期边界额外排入下一轮；切换场景会取消飞剑、排队轮次和按住状态。没有改动或强制跳过 Boss 阶段、收尾剧情及胜利条件。

新增 18 项离线规则检查，覆盖十轮击杀 2000 血目标、阶段边界截断、阶段同步后不重复扣血、连发节奏、不同血量比例、多目标和换场景取消。本版共 595 项纯规则／协议检查通过，主 Mod 编译通过。没有启动或关闭游戏；截图中的黑屏是否完全解决、无上辐光全流程是否正常仍需玩家重开该场 Boss 战确认。数值检查不等同于实机通关验收。

更新保留背包、配装、方块与存档。关闭游戏后更新，使用原启动器入口；不需要重开冒险存档。
