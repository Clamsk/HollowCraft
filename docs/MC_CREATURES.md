# 船与 MC 生物

## 船

把船移到快捷栏，选中后右键指向地面附近的空位或水面。船有原版宽度，需要留出左右空间；它会落到地面或浮在水上。支持原版木船、竹筏及其运输船版本，普通船两个座位、运输船一个座位；运输船可打开原版容器界面。

空洞中有原生受击体的敌人，以及识别到的 NPC、可移动小生物，接触有空位的船后自动成为乘客。对空洞大体型生物放宽原版宽度限制，使用同一运动根去重，避免 Boss 的多个受击部位占用多个座位。高速移动会检查两次姿态之间的接触路径。

捕获后固定原生身体位置，不禁用整套 FSM。原来的攻击、受伤、阶段与死亡流程仍由空洞处理；原角色保持自己的二维画面，船使用 MC 三维模型。离开视野仍保留捕获；死亡、船被破坏或换场景时清理约束并恢复运动属性。跨场景重新加载的原生角色不保证保留上次捕获身份，因为原版会重建这些角色。

攻击乘客仍使用方向攻击；要拆船，请明确把准星指向船再左键。玩家右键空船可上船，Shift 下船；船没有加入 A/D 划桨控制。MC 生物上船的姿态走原版模型渲染。

新存档和 Boss 录制背包各有一艘橡木船；旧存档补发一次，不改九格快捷栏。也可用工作台按原版配方制作，或从创造菜单拿取。

## MC 生物

按 E 打开创造菜单，在「生成蛋」分类或搜索中取用生成蛋，选中后右键放置。**生成蛋不加入生存初始背包。** 当前本机版本的原版生成蛋资源目录见 [creatures.json](../release/creatures.json)；这是静态资源目录，不代表逐个生物已实机验收。

使用真实 MC 实体，包括动物、敌对生物、水生生物、飞行生物与村民等。模型、幼年/变种数据、血量、护甲、攻击、原版掉落、经验、喂食、繁殖、驯服相关互动及容器请求沿用 MC 的对应实现。近战可以命中这些实体；箭、药水、爆炸及环境伤害也由 MC 处理。普通右键先尝试原版实体互动，再尝试放置或使用物品。

为适应二维地图，实体深度、移动目标与寻路厚度限制在同一平面，保留身体的原版宽高。同步实体附近的空洞碰撞地形；超出同步范围或尚未收到地形时暂停实体模拟，回到范围再继续，防止在无地形数据的区域掉落。后台采用固定夜间，避免空洞洞窟错误产生日晒；实体展示使用清晰的 MC 模型照明。

复杂三维导航、额外坐骑的驾驶、结构/维度依赖行为和特殊 MC Boss 流程仍需适配；这版不能视为已经完整还原每一种生物的所有玩法。普通存档的 MC 实体保存在独立 MC 世界中；Boss 录制重打换用新存档身份和房间区域，不沿用上一场召唤物。

## 试玩

两端编译和发布包检查后直接交给玩家，未启动游戏。建议先放船捕获普通敌人，再用启动器测试不同 Boss；创造模式依次生成牛、羊、僵尸、骷髅、蜘蛛、狼、村民、鱼及飞行生物，反馈捕获、碰撞、战斗与互动的实际表现。发生问题时附上版本、生物/场景、操作，以及两端日志。
