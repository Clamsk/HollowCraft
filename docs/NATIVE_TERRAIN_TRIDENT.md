# Native alpha.10：空洞原生地面与三叉戟瞄准

[English](NATIVE_TERRAIN_TRIDENT.en.md) | 简体中文

alpha.9 的人工薄平台检查没有覆盖空洞地面的实际碰撞类型。读取本机 `Tutorial_01` 场景后确认，主要地形块使用没有填充面积的 `EdgeCollider2D`。旧逻辑从整个碰撞器的包围盒和单个最近点推测实心区域，会丢失水平地面，也可能把空气误记成障碍。水继续向地板下方流，因此画面只看到一根水柱。

现在直接读取 Edge、Box、Polygon、Composite 和 Circle 碰撞器的真实轮廓，转换为世界坐标后按格细分。边缘线使用极薄的边界，查询范围也覆盖正好位于格线上的零厚度碰撞。采样轮廓和横切结果在每次地形刷新内复用。地面扩散按矩形集合的覆盖和方向通道判断，液体记录进入单元格的方向，坡面显示使用分段底部。

离线回归使用了从本机提取的教程 `Chunk 0 1` 实际轮廓：[数值样本](../tools/fixtures/tutorial-edge-floor.json)。检查水柱落地后向两边各流七格、不进入地板下方，以及旧存档中卡住的水柱恢复扩散。另覆盖了斜边和包含采样中心的部分实心多边形。没有运行 Unity 或游戏；不能把这些检查等同于实机验收。

三叉戟蓄力时之前仍使用 `trident_in_hand`，漏掉原版 `trident_throwing` 的手持显示参数。现在主手与副手都会在蓄力时切换对应模型，松开后恢复普通握持；瞄准手臂改为水平向前基准并叠加光标仰角，修正原来的额外向下偏移。未改 Better Combat 攻击动作时序。

主 Mod 编译通过，共 577 项纯规则／协议检查通过。更新程序会保留背包、方块、水源和存档；已有错误下流会按正常规则退去，不需要重开存档。本机私有副本和安装包均更新到 alpha.10。实际画面仍由玩家在相同位置试玩确认。
