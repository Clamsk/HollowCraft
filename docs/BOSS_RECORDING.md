# Boss 录制启动器

[简体中文](BOSS_RECORDING.md) | [English](BOSS_RECORDING.en.md)

运行 **HollowCraft Launcher.cmd** 或 **Start HollowCraft.cmd** 打开图形启动器。初次安装仍先运行 **Install HollowCraft.cmd**。原先的桌面启动入口也会打开同一个界面。

1. 选择「Boss 录制」页，用中文或英文查找 Boss。
2. 选择原版调谐、进升或辐辉难度，以及 1080p / 720p 游戏窗口。
3. 点「开始 / 切换 Boss」。启动器会启动两端游戏，创建独立录制存档并自动进入挑战；首次打开需等待 Minecraft、空洞及原生神居入场流程。
4. 游戏运行后，可以在启动器中继续换 Boss，无需重启两款游戏。录屏使用自己的 OBS 等工具；启动器负责准备战斗场景。

| 操作 | 效果 |
| --- | --- |
| F5 | 重打当前 Boss，重置本场 MC 装备、生命、饥饿、经验、药水效果及放置物 |
| F6 | 返回神居雕像大厅（Hall of Gods / GG_Workshop） |
| F8 | 隐藏或显示游戏左上角录制提示 |
| MC 死亡界面「重生」 | 在录制模式中重新准备当前 Boss |
| 停止并保存 | 关闭本工具启动的游戏并保存；启动器关闭后游戏可继续运行 |

每场使用**生存模式初始装备**：全铁套、铁剑、弓、64 箭、64 牛排、64 末影珍珠、192 圆石、64 橡木原木、打火石、64 TNT、水桶、岩浆桶、盾牌、铁斧、铁镐、64 火把、64 铁锭、64 金苹果及两个不死图腾、64 基岩、一艘橡木船。生成蛋不加入生存初始背包。快捷栏 1–9 为铁剑、弓、金苹果、圆石、水桶、岩浆桶、TNT、打火石、末影珍珠，箭与其余材料在背包。基岩生存模式不能挖掉，创造模式可以挖除；录制重打会重置上一场方块。没有自动给予创造专属三叉戟。物品消耗、耐久、食物、护盾及受伤规则继续生效。

启动器包含从本机原版神居雕像配置整理的 **45 个挑战入口**，包括黄蜂女、格林、螳螂领主、纯粹容器、梦境变体、战斗姐妹及永恒的折磨。三个难度使用原版各自的场景配置，部分进升/辐辉场地因此不同。另外提供空洞骑士和辐光两个**剧情场景**，只提供标准难度；这两个入口及其剧情/结局时序尚未实机验收。45 个挑战入口含永恒的折磨等特殊挑战，不等同于 45 种独立 Boss。

录制本地存档位于 `runtime/hk-boss-saves/<本次录制编号>`；每场 MC 使用新的独立存档身份。普通游玩的存档、装备与进度保留在原来的目录。要从普通游玩切到录制，先点「停止并保存」。录制时切换或重打会放弃当前场战斗和本场装备变动，这是重新准备初始装备的正常行为。

格鲁兹之母孵化小虫后开门的问题属于普通地图 `Crossroads_04` 的战斗流程，原版神居挑战与该孵化流程不同。请用普通存档反馈这一修复的效果。

本版确认过 PowerShell 5.1 启动器控件初始化、47 项目录及两端编译，未启动游戏验证全部挑战或剧情场景。
