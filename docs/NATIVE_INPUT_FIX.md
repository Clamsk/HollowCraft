# Native alpha.4：实际输入、连招与工作站

[English](NATIVE_INPUT_FIX.en.md) | [迁移清单](NATIVE_MIGRATION.md)

这是独立版的下一轮修复与迁移，仍不代表桥接功能全部完成，也没有完成实机通关验收。玩家端仅运行空洞，不启动 Minecraft、Java 或第二个窗口。

## 这次修复的根因

共享前端右键发送 `interact`，同时携带光标目标、实际放置格子和当前脚底坐标。旧本地后端只把该命令当成“打开容器”，没有继续处理方块和物品使用。旧检查直接调用后端的 `place`、`itemUse.start`，绕过了真实输入，因而漏掉这个问题。本版让前端与纯规则检查共用数据包构造，按同一路径检查放置和拉弓。

- 先交互指向的工作站／门，潜行时可跳过方块交互；再按主副手优先级放置或使用物品。目标格与放置格不再混用。拒绝放置时撤销预测方块。
- 跳搭使用点击时的脚底位置和实际人物宽度；脚底刚越过方块顶部即可放置，避免旧坐标把合法放置误判为穿进人物。
- 长按右键不会反复重置拉弓计时，松开走同一物品使用协议。投射物按 Unity 实际扫掠结果前进；已放置 MC 方块和 MC 生物不再被独立版忽略。薄平台所在的采样格不会被当作完整实心方块，导致箭停在半空。

## 人物与攻击

原桥接的 GUI 人物矩阵与本地骨骼适配之间缺少一次整体 X 反射。本版在人物根节点统一补偿，身体、护甲、手持物和背包预览采用同一方向，避免对各肢体重复翻转。

继续读取同一套 Better Combat 静态武器配置和右斩／左斩／突刺文件，补上默认 `TransmissionSpeedModifier` 的前摇加速、后摇速度和三 tick 停止过渡。连招从上一段最终姿态混入下一段，避免每段先跳回站姿。取消攻击会作废对应的伤害请求。锋利附魔额外伤害在暴击基伤计算后叠加。

物品 GUI 模型使用原版 `gui` 显示变换。药水、药箭、生成蛋和皮革物品图标根据 NBT／注册表着色，手中对应分层纹理也应用颜色。尚未实现护甲纹饰、全部染色护甲层和完整附魔光效。

## 本轮继续迁移

- 创造菜单使用原版 13 页的类型、位置、图标和排序数据，来源为 1523 条原版目录堆栈，包含药水和附魔书 NBT。运行时过滤尚未迁移的生物生成蛋，加入已保存快捷栏预览；搜索、数字键取物、C/X 保存／读取快捷栏接入本地存储。
- 铁砧：修复材料、同类工具合并、兼容附魔合并、改名、经验等级费用与消耗。砂轮：修复、去除非诅咒附魔、保留两侧诅咒和返还经验。
- 附魔台：青金石、经验、书架数、物品附魔能力、等级范围与附魔兼容性。随机分布为本地实现，并非与 Java 随机种子逐次一致。
- 切石机：原版配方选择及 Shift 批量取出。锻造台：模板、基底、材料三输入，升级保留工具 NBT，纹饰写入 NBT；纹饰显示仍待迁移。
- 经验总量、等级、进度和附魔种子保存到独立存档。关闭工作站归还输入，输出为计算预览，避免虚拟结果重复存储。
- 弩的多重射击产生三条轨迹；穿透可穿过生物并限制重复命中。无限／创造箭不会被回收复制。忠诚三叉戟可见返航，切场景时回收，避免遗留在旧房间。
- 九种现有 MC 生物使用本地关节几何和原版静态皮肤；新增基础种类掉落。有限的朝向／步态帧按种类共享，避免每只生物每帧软件重绘，销毁模型时释放动态网格。它们仍不等价原版完整模型和 AI。
- 本机准备 149 个原版／Better Combat 音频文件，76 个事件映射；已连接脚步、放置、挖掘、挥击、受伤、盾牌、图腾、饮食、弓箭和爆炸等事件。映射数量不代表全部事件都已接入。音频按需加载，不进 Git 或发布包。

## 检查与试玩

本轮通过 111 项纯规则／协议检查及 12 项启动器检查。检查覆盖前端真实数据包、三连招顺序和时序、放置边界、拉弓释放、菜单字段、工作站材料守恒、投射物应答与忠诚返航。编译和这些检查不证明实际骨骼外观、帧率或 Boss 流程已正确；本轮没有启动、关闭游戏或自动游玩。

更新后直接运行 **Start HollowCraft Native.cmd**。已有独立版存档保留，不会为了测试清空背包。

接下来仍需迁移完整生物 AI／物种、特殊动态配方与物品、滞留云、复杂红石和流体细节，并由玩家验收战斗、建造和完整剧情。详细未完成项持续保留在 [机器清单](../release/native-migration.json)，不以静态数据覆盖冒充玩法完成。
