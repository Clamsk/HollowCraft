# Native alpha.8：手持物品绑定与启动器配装

[English](NATIVE_HANDS_LAUNCHER.en.md) | 简体中文

本版处理独立版的武器绑定、盾牌模型、落地水、死亡物品规则与启动器。沿用现有 Better Combat 身体动画和连招时序。完整功能迁移及完整通关仍未验收。

## 武器与盾牌

Better Combat 的 `rightItem` / `leftItem` 是独立于手臂的物品轨道。之前独立版只应用了身体骨骼，漏掉了这些位置与旋转轨道。本版在原版握持矩阵之后应用物品轨道，并处理本地坐标镜像和连招过渡。已烘焙握持矩阵的模型使用 `G * A * inverse(G)`，避免把握柄变换应用两次。

盾牌与三叉戟手持模型改为原版静态部件、关节和 UV 数据；无图案盾牌改用 `shield_base_nopattern.png`。人物、武器与盾牌继续共享逐像素深度和透明像素判断，修复空手切换到内置模型时未重新启用挂点的问题。

## 启动器

运行仓库或安装包根目录的 **HollowCraft Launcher.cmd**，或 **Start HollowCraft Native.cmd**。

- **冒险**：继续游玩、安装／更新；配置死亡后保留背包与装备、自动落地水及收水等待。
- **初始配装**：点击 36 个背包／快捷栏槽位、4 个护甲槽或副手，进入物品库挑选；右键槽位清空。
- **创造物品库**：按原版分类、中文／英文名／ID 搜索，设置数量，选择药水和附魔书变体。方块图标由本地静态模型和纹理生成，无需运行 Minecraft。
- **Boss 录制**：选择 Boss 和难度；每场使用独立存档、生存模式与当前配装。

提供经典铁装、轻装开荒、弓箭手、下界勇士、Clamsk 彩蛋演示、空手生存六个预设。Clamsk 预设包含天顶剑和装备在胸甲栏的星尘翅膀。

配装默认只用于新存档和新录制场次。勾选“也应用到已有存档”会替换该存档背包和装备；同一配装版本对每份存档只应用一次。再次继续游戏、修改收水时间或死亡规则不会重新发放装备。修改配装后才会产生新的配装版本。

配置保存到解压目录的 `hollowcraft.native.settings.json`，写入前保留 `.bak`。配置、备份与玩家存档不上传 Git，也不进入安装包。规则在下次启动游戏时读取。

## 生存与落地

默认保留死亡物品。关闭保留后，背包、护甲、副手和合成／光标中的物品掉在死亡场景，可返回拾取；消失诅咒物品不掉落。图腾成功救命不掉装备。此开关控制物品，当前不改变经验保留规则。

生存模式下落距离 **≥ 12 格** 且有水桶时自动放水，教程新存档第一次落地也会触发。自动收水默认 **2 秒**，启动器可选 1／2／3／4／6 秒；收水计时随存档保存。脚底被方块占用时寻找可用位置，半砖支持含水；回收时保留原半砖。自然水不会被自动收回。关闭自动落地水后，使用普通摔落伤害规则。创造模式 **> 12 格** 沿用超英落地。

Boss 录制左上角提示改用可换行字体和动态高度，Geo 显示避开该提示框。

## 检查与素材

通过主 Mod 编译、511 项纯规则／协议检查、12 项启动器进程检查、17 项配装及离屏界面交互检查。对照本机原版 PlayerAnimator／JOML，29 段动画的 334,584 个轴采样、4,782 个身体关节点和 1,594 个物品握持点均在容差内。没有启动或关闭游戏，画面、操作手感和 Boss 通关由玩家试玩验收。

启动器使用实际 WPF 控件；背景是生成插画，右下角为 `produced by clamsk`。[背景文件与完整生成提示词](LAUNCHER_ARTWORK.md)。Minecraft 原版纹理、语言和动画在安装时本地提取或按固定哈希获取，不随仓库与发布包分发。
