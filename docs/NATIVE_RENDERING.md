# Native alpha.3：人物渲染、战斗动作与数据迁移

[English](NATIVE_RENDERING.en.md)

本版修复手持变换和人物遮挡，并继续迁移配方、酿药、弩和部分附魔规则。仍是独立版迁移预览，尚未完成桥接版全部功能，也没有经过完整通关验收。

## 人物与手持物品

- 装备、身体、左右手物品共用逐像素深度测试。透明像素不写深度，避免原先按三角形中心排序造成的错误遮挡。实际关节网格在本机渲染，无 MC 画面回传。
- 读取静态原版物品／方块模型 JSON 的继承、纹理、几何与第三人称显示参数。左右手分别应用握持变换；盾、格挡盾、三叉戟使用对应实体模型变换；拉弓和弩装填切换对应模型。
- 护甲按同一套骨骼定位，区分内层护腿和外层头盔／胸甲／靴子，保留皮肤外层。鞘翅和特殊翅膀沿用本地绑定。
- 读取 Better Combat 的武器配置与静态动作数据。剑使用右斩、左斩、突刺；换武器或连招超时重置。`body` 控制整个人物，`torso` 控制胸部，六个肢体按各自旋转与位移采样，包含准备和恢复阶段。

这是独立 C# 兼容实现，没有在 Unity 中直接运行 Minecraft 的 PlayerEntityRenderer、Better Combat 或 PlayerAnimator。Bendy 的肢体弯曲、原版全部使用姿势、特效和过渡细节尚不等价。

空洞当前资源中没有可用的通用深度裁剪着色器，本版使用固定大小的本地软件深度缓冲，输出一张透明纹理。场景画面为 256×256，特殊翅膀为 384×384，最多每秒更新 40 次；网格和纹理像素缓存，背包预览只在打开界面时持续更新。没有启动第二款游戏或逐帧文件传输。实际帧率和手感仍需玩家试玩评估。

## 本次继续迁移的规则

- 导入原版 1.20.1 的 1255 条物品静态记录：堆叠数、耐久、攻击属性、食物、燃料、护甲、默认方块硬度与碰撞等。目录数据不等于每个物品的特殊行为均已实现；没有模型／AI 的生成蛋不展示为可用生物。
- 导入 822 个有序／无序合成配方和 112 个烧制配方。支持递归物品标签、替代材料、镜像有序配方；无序配方用完整匹配处理重叠材料选择。特殊动态配方、锻造和切石仍待迁移。
- 合成归还桶等剩余物。熔炉、高炉、烟熏炉分开匹配输入与烧制时间，高炉／烟熏炉燃料使用时间相应缩短，输入变化时重置进度。
- 酿药台支持三瓶一批、烈焰粉燃料、400 tick 进度、原版药水／喷溅／滞留瓶型转换。导入 251 条酿造转换关系与 43 种药水数据，计时、燃料和瓶内 NBT 保存到独立存档。
- 创造菜单增加药水和药箭变体。饮用按数据应用效果，喷溅伤害和治疗、部分持续效果及药箭效果已接入。水不再造成虚构伤害；滞留药水云、全部药效视觉和生物特有免疫仍待迁移。
- 弩先装填再发射，已装填状态保存在物品 NBT；接入快速装填。弓支持箭种选择、力量和无限附魔，已接入锋利、效率、耐久、防护及部分分类防护的规则。并非全部附魔实现。
- 使用默认方块形状的二维投影作为碰撞信息；需要工具的采集判定、效率与水下速掘已接入。完整朝向／含水等方块状态、掉落表仍待迁移。

## 安装、开发和验收

关闭正在运行的独立版后运行 `Install HollowCraft Native.cmd`，再运行 `Start HollowCraft Native.cmd`。更新保留独立版存档，不会自动重置已有背包。首次安装从锁定版本且经过校验的资源归档提取静态贴图、模型 JSON、配方和动画，不要求玩家安装或运行 MC、Java、Fabric。

`release/native-registry.json` 是预先导出的数值和注册表事实。开发者工具 `tools/export-native-rules.ps1` 需要本地缓存的映射依赖和 JDK，仅在构建时启动注册表导出工具，不创建客户端、服务器、世界或窗口；导出器和 Java 二进制不进入玩家安装包。

规则检查包括逐像素遮挡、透明像素、动画轴和恢复、配方标签、烧制分类、酿药、弩、药水及已有存档／战斗规则。没有启动或关闭游戏，也没有执行自动实机游玩。实机装备遮挡、攻击手感、帧率与 Boss 流程交给玩家验收。后续状态见 [迁移清单](NATIVE_MIGRATION.md) 和 [机器可读清单](../release/native-migration.json)。

动画语义参考：[PlayerAnimator](https://github.com/KosmX/minecraftPlayerAnimator)、[Better Combat 1.20.1](https://github.com/ZsoltMolnarrr/BetterCombat/tree/1.20.1)。
