# HollowCraft Native 1.0.0 · 首个正式发布版

[English](NATIVE_RELEASE_1.0.en.md) | 简体中文

发布日期：2026 年 10 月 20 日。正式版以 0.40.0-alpha.12 为基线，保留该版玩法、数值、存档格式和功能。本次整理版本标识、启动器说明、安装包与 GitHub 正式发布，不新增玩法改动。

## 安装与更新

需要 Windows x64 和 Steam《空洞骑士》1.5.12620。无需运行 Minecraft、PCL、Java 或 Better Combat；发布包无需 .NET SDK。首次安装联网准备经校验的依赖和静态素材，不包含原版游戏文件、提取素材或个人存档。

1. 下载并解压 `HollowCraft-Native-Windows-1.0.0.zip`，放在 Steam 原游戏目录以外。
2. 运行 `Install HollowCraft Native.cmd`。
3. 运行 `HollowCraft Launcher.cmd`，选择普通冒险或 Boss 录制，并按需配置生存初始装备和死亡掉落。

从 alpha.12 更新时，关闭游戏，将包内文件覆盖到原来的 HollowCraft 工作目录，再运行安装器。保留 `runtime`、`hollowcraft.native.local.json` 和 `hollowcraft.native.settings.json`，无需重开冒险存档。已经卡住的单场 Boss 战应在更新后重新挑战。

## 收录内容

- MC 风格的三维人物、装备、攻击动作、生存数值、背包和工作站，以及方块建造与跳搭。
- 生存／创造模式、创造物品菜单、启动器配装方案和 Boss 录制入口。
- 武器、弓箭、药水、流体、盾牌、不死图腾、船与已接入的 MC 生物行为。
- 输入 `Clamsk` 获取天顶剑与星尘之翼。天顶剑每轮飞剑对每个目标最多造成 200 点空洞原生伤害，继续遵守 Boss 阶段边界。
- alpha.12 的假骑士／失败冠军头部阶段守卫、岩浆伤害与无拉扯、方块覆盖流体、药水喷溅粒子与声音修复。

## 已知限制与检查范围

MC 和旧桥接版的全部功能仍未等价移植，复杂物品、生物行为、流体和高级红石等仍持续完善；逐项状态见[功能清单](NATIVE_MIGRATION.md)。所有 Boss／剧情组合和完整通关尚未全面验收。正式发布保留这些限制，不将版本号视为全部功能完成的证明。

基线已通过 630 项离线规则／协议检查，并保留已有启动器检查记录。本版重新编译、核对功能代码及安装包内容；没有启动、关闭或自动游玩游戏。更新不修改 Steam 原游戏文件。旧 alpha.12 和 v0.30.18 桥接发布保留供回退。
