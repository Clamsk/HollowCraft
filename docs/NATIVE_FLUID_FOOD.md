# Native alpha.9：进食音效与流体修复

[English](NATIVE_FLUID_FOOD.en.md) | 简体中文

进食现在会在使用动作中按节奏播放原版咀嚼声，吃完再打嗝。喝药和牛奶播放饮用声，松开使用键后停止后续声音与消耗。相关音频提前加载，沿用原有空洞音效音量设置。

水和岩浆不再把每个水位都渲染成缩放的静止方块。流体使用独立网格、连续的斜面边缘和地形裁切；浅水只裁去未填充部分，不拉伸整张贴图。静止水／流动水、静止岩浆／流动岩浆使用各自的原版纹理与动画元数据，包括岩浆的往返帧序列。水使用透明混合材质。

扩散继续在封闭二维平面中运行：水每 5 tick 更新、横向最多七格；岩浆每 30 tick 更新、横向最多三格；向下优先，水平流动搜索附近较近的落差。下落水柱恢复完整流量，移除水源后逐步退流。水源更新、石头／圆石／黑曜石生成和海绵吸水规则保留。

流体前缘会请求实际空洞碰撞数据。未采样的区域不会被当作空气，刚进入场景时先等待地形数据；原有地形数据会保留，直到对应位置重新采样。原来的薄平台即使没有填满整格，也会阻挡向下流动，并裁切流体显示。前缘新增地形只采样一次，玩家附近区域继续定期刷新。

同时修正半砖碰撞数组被展开的问题，半砖以半格外观显示；含水半砖的水仅出现在空余部分。水位改变会更新渲染状态，已有流体网格直接更新，避免反复销毁和创建整个对象。水／岩浆浸没深度与溺水判断使用新的液面高度。

更新后运行安装器，以补齐流动贴图的动画元数据；无需运行 Minecraft 或 Java。原版贴图和音频仍只在本地准备，不进入 Git 或发布 ZIP。旧存档水源、方块和背包数据继续保留。

本版通过主 Mod 编译及 549 项纯规则／协议检查，新增覆盖进食中途音效与取消、七格／三格扩散、相邻液面连续性、水位刷新、薄平台、未采样地形、进场等待和含水半砖。没有启动、关闭或自动游玩游戏，实际画面与手感由玩家试玩验收。二维流体并不等价于完整的 Minecraft 三维流体实现。
