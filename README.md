# HollowCraft 0.12 试玩版本

Minecraft-style survival and combat in Hollow Knight

本版编译后直接交付玩家试玩，不执行自动实机验证。最新改动见《试玩说明-0.12.md》，初始装备延续 0.6。后文已有测试记录仅对应其注明的旧版本。运行职责与独立 Mod 路线见 [架构说明](docs/ARCHITECTURE.md)。

GitHub 中的 `v0.8.0` 是后续修复前的源码基线。0.9 针对玩家反馈的进食、原生地形投射物碰撞、创造目录、跳搭和攻击漏响应修改实现，实际效果待玩家试玩。下文的功能描述不代表新版本已通过实机验收。

此仓库只发布自编写源码与脚本，不包含游戏文件、提取素材、依赖二进制、运行副本、日志或存档。克隆仓库不能直接启动游戏，构建及本机依赖说明见 [SOURCE_SETUP.md](SOURCE_SETUP.md)。

0.8 将普通敌人（原生血量不超过 60）换算为 18 点 MC 血量，铁剑正常满伤约三次命中；更强敌人与 Boss 仍保留更高血量。新建空洞存档拥有独立的 MC 背包、盔甲、副手、耐久、经验与房间方块；重新创建相同槽位也会生成新的身份。新游戏第一幕落地自动放水并收回，其后生存模式落差至少 12 格触发。人物位置同步为 20 Hz，右键长按连续放置，支持对已有方块的上表面放置和部分原生地面的基础方块。攻击输入使用可靠消息与顺序点击队列。

0.7 角色改用 Minecraft 的第三人称 PlayerEntityRenderer：在 MC 内渲染真实模型、护甲层、主副手层、物品使用模型和 Better Combat／player-animation-lib 动画，带透明背景和深度缓冲，再将整个人物的透明帧送入空洞二维场景。空洞端不再分别重建、排序这些人物装备。姿态控制与真实玩家装备使用独立副本传给渲染线程；渲染不会改变真实背包。正常角色帧约 20–30 FPS，位置跟随空洞每帧更新。MC 与空洞需同时运行。

Minecraft 1.20.1 的生存玩家、物品栏、方块、合成与容器接入 Steam《空洞骑士》1.5.12620。空洞负责二维场景和碰撞，真实本地 Minecraft 服务器负责血量、护甲、饥饿、食物、物品及配方。两端通过 localhost:31674 通信。

## 启动

保持 Steam 登录，双击 Start HollowCraft.cmd。等待 Minecraft 自动进入独立世界，保持它运行，然后在空洞测试副本里新建或读取试玩存档。进入地图默认生存模式，角色是 Steve。在长椅保存空洞进度后，双击 Stop HollowCraft.cmd 可保存 MC 世界和物品并退出两端；只关闭空洞后再次启动会复用本项目的 MC 后端。

试玩使用 runtime/minecraft 与 runtime/hk-test-saves。自动测试使用 minecraft-smoke 与 hk-smoke-saves。Steam 原程序集、PCL 配置及个人存档不改动。测试副本通过硬链接或目录联接复用部分只读资源，请勿编辑这些资源目录。Java 参数文件采用本机 GBK 编码并验证往返，避免中文路径乱码。

原 Knight 外观、面具/灵魂 HUD、骨钉按键、法术、冲刺、二段跳、蹬墙跳与超级冲刺已退出玩家操作。原生剧情获得标记仍保留，避免破坏过场与地图流程。启动与存档选择仍使用空洞主菜单，剧情地图及 NPC 保留。

2026-10-10 操作修复：走路与奔跑采用 1.20.1 LimbAnimator/BipedEntityModel 的步频、平滑与摆幅；蹲姿采用原版身体 0.5 弧度、肩与髋部偏移，攻击继续叠加 Better Combat 关键帧。主副手分别导出完整原版握持矩阵，消除坐标翻转和重复旋转。点击空洞地面会选择其空闲上表面，透明预览与实际放置一致；薄平台代理保留实际高度。

受伤由 MC 决定无敌帧、原有速度的一半与击退，不再叠加客户端假击退；Steve 闪红保持不透明，物品不染红，血条保留上一血量并闪白。二维原生碰撞负责玩家墙面碰撞，关闭由 MC 投影墙体产生的额外窒息判定，避免门边误伤。真正的陷阱、敌人、岩浆和溺水等仍走 MC 伤害规则。

四模式菜单支持创造、生存、冒险、旁观。冒险模式限制普通方块编辑；旁观模式可以穿过地形，A/D 移动、Space 上升、Shift 下降、Ctrl 加速，并免疫普通接触伤害；退出旁观自动恢复实体碰撞。四模式切换不领取测试物品。

## 生存与界面

血量、饱食度、护甲、经验条、快捷栏、副手与装备槽读取真实 MC 玩家。空洞普通接触的一个伤害单位转成三点 MC 基础伤害（普通僵尸在正常难度的攻击基准），再由 MC 计算护甲、韧性及伤害抗性。普通接触不会传送回起点；受伤有闪红、短暂击退和保护间隔。陷阱与真正死亡另行处理。饥饿、饱食回血、进食消耗、死亡、装备掉落与重生使用 MC 规则。死亡及丢弃的物品在当前场景按 MC 重力落地，显示三维模型或透明图标，接近后按拾取延迟与背包容量收取。

游戏内背包、工作台、熔炉、箱子和 HUD 使用本机 MC 原版贴图。背包有真实 2×2 合成，工作台有真实 3×3 合成。界面操作调用真实 ScreenHandler，支持拾取、拆分、快速移动、装备及原版配方。熔炉使用真实燃料和烧炼进度。打开界面会阻止常规输入；已开始的鞘翅滑翔继续运行。站立碰撞体为 0.6×1.8 格，下蹲高 1.5 格，滑翔高 0.6 格，切换姿态保留脚底位置。

新世界直接穿全铁套，副手盾牌；提供铁剑、弓、64 支箭、64 牛排、64 末影珍珠（四组，每组 16）、64 圆石、64 橡木原木、打火石、64 TNT、水桶、岩浆桶、铁斧及 64 火把。旧试玩存档首次连接本版时补齐这份清单并装备铁套和盾牌，原物品保留；背包满时多余物品掉落。之后重连不重复发放。每次连接默认回到生存模式。

## 战斗与范围

读取实际安装的 Better Combat 1.8.5 武器注册表，包括冷却、前摇、伤害倍率与连击；动作由 MC 内的 Better Combat 动画接口及 player-animation-lib 在真实玩家模型上播放。攻击距离采用原版 MC 1.20.1 的 3/6 格；普通方块交互为 4.5/5 格。根据光标左右侧攻击该侧范围内的目标，保留墙体遮挡，取消指针角度／突刺窄框条件。允许空挥，单击结束回位，冷却中再次单击可缓冲一次连击。命中经过空洞原生 HitTaker 与受击事件处理，支持敌人伤害、击退及原本可破坏的物件/障碍。永久地图地形仍不可挖，剧情门是否能破坏遵循它本身的空洞规则。

采掘按服务器每秒 20 tick，使用原版 calcBlockBreakingDelta × 持续 tick 数；硬度、工具、适用工具、效率附魔、状态效果、在空中或水中的罚速均由 MC 计算。游玩不再使用客户端报出的长按时长决定是否破坏。

物品栏使用 MC 自身 DrawContext/ItemRenderer 烘焙为透明 64×64 图标，保留三面和原版 GUI 光照。人物及装备的完整渲染由 MC 第三人称渲染器负责，包括护甲、盾牌防御、弓的拉弦模型、附魔与材质深度；地上物品仍读取 BakedQuad。药水按 NBT 单独导出颜色。耐久计算由真实 MC 物品及玩家负责，界面采用原版 13 像素取整长度和 HSV 色条。箭使用原版投射物贴图及交叉平面模型，位置每个 MC tick 推送，并发送生成／命中事件，空洞端插值显示飞行。首次进入世界自动生成缓存。

战斗采用不可见 MC 生物代理，调用真实 PlayerEntity.attack，保留冷却、1.5 倍下落暴击、附魔、耐久及伤害小数。普通小敌人换算为 18 点血，较强敌人保留较大血量（上限 1024），剩余血量比例转换回原生 HealthManager。幽灵与阴影按亡灵分类，其余默认节肢；目前使用自定义零护甲代理，尚未逐种配置全部抗性和行为。

TNT 使用真正的 MC 点火、80 tick 引信、爆炸、方块抗爆性、距离和遮挡伤害；爆炸结果作用于空洞敌人及可破坏物件代理。二维背景的临时支撑允许在准星的空格放置普通方块；特殊方块仍必须通过原版放置规则。空洞地形的 MC 遮挡由格子近似。

这是可试玩原型，尚不能宣称已完成生存模式全流程通关。Minecraft 负责数值与原版物品逻辑，空洞保留原生 AI、地图、剧情与碰撞。场景仍是二维世界，人物与手中物品是真正的三维网格，不是三维空洞地图。

0.5 加入真实水/岩浆与桶、混合生成石材、部分方块精细碰撞、门开合、拉杆与红石灯状态；弓弩、三叉戟、盾牌、各类投掷药水、末影珍珠、鞘翅与烟花使用 MC 原生实体/状态。原版重力按 20 Hz 积分，普通跳跃实测约 1.252 格。鞘翅使用原版二维投影的飞行公式；水中移动是近似值。红石由 MC 原版更新驱动，已验证拉杆/灯，复杂活塞机构尚未验证。

酿造台执行真实 400 tick 配方与燃料；铁砧执行命名、费用和结果；附魔台使用真实随机附魔与青金石。容器槽位及坐标来自原版 ScreenHandler。砂轮等通用槽位可接入，但织布机、切石机等专用配方选择按钮还未实现完整界面。水、岩浆与燃烧火焰读取原版动画帧及 .mcmeta 帧时长；物品图标保留缓存帧。特殊内置物品模型、附魔流光、全部 Better Combat 条件攻击及双持连击仍有缺口。

空洞可破坏物和敌人获得自定义 MC 生存材料掉落，原生死亡确认后才发放，避免 Boss 阶段转换提前发奖励。这是桥接项目的进度设计，不是原版 MC 生物掉落表。长椅保存两端进度、恢复 MC 状态，死亡回到原生存档点；原生 NPC 文本通过新界面翻页。MC 风格商店读取原生商品、中文名称、价格和购买条件，调用原生确认逻辑扣除吉欧和设置剧情标记，已验证购买灯笼和取消守恒。十字路驿站的实际收费对话已验证取消守恒、支付 50 吉欧、开放站点与恢复输入；梦境、驿站旅行选择和最终结局仍需逐项验收。

两端暂停同步；断线时冻结空洞场景并等待重连，保留方块碰撞。临近掉落按 MC 重力落地，离场掉落冻结。切换手持模型时释放排序网格，复用材质与排序缓冲。GUI 模型使用 RGBA 缓存 item_models_rgba，保留透明像素；旧黑底缓存不再使用。
